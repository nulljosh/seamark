Sextant

A sextant fixes your position by observing what's visible, without instrumenting anything. This library does the same for a web page: it reads real values out of rendered graphics. Draw below — nothing here knows what you meant to draw, it only measures what's on screen.

Every number is derived from the drawn path — sampled, mapped out of SVG user units, and reported in grid coordinates.

Why this is harder than it looks. A browser graphic lives in four coordinate spaces at once: SVG user units, CSS pixels, the frame's own viewport, and screenshot space. Mixing any two produces plausible numbers rather than an error, so a reading can be quietly wrong for hours. sextant keeps each conversion explicit, samples paths into data space, matches labels to the edges they annotate, and compares expressions by fingerprint rather than by string — because x(x+8) and x²+8x look nothing alike, and agree at exactly the point you'd test first.
