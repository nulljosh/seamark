# Seamark

Reads values off rendered charts: coordinate reconciliation, SVG path sampling, circle fit, expression fingerprinting. npm library plus a demo at seamark.heyitsmejosh.com. Was sextant.

- `src/` is the library, `test/` runs with `node --test`, `public/` is the demo
- `ios/`, `watchos/`, `kmp/` wrap the demo; the real logic is JS. Android build needs JDK 17
- npm publish is still open. Six UI languages
